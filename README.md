# Secure Cloud Native E-Commerce Platform

## SE4030 – Secure Software Development Assignment

This repository contains the security-enhanced version of the **Cloud Native E-Commerce Platform** developed as part of the SE4030 – Secure Software Development group assignment.

The project was analyzed using security testing and source-code review techniques to identify potential vulnerabilities. The identified vulnerabilities were then remediated where feasible, and the application was retested after applying the security fixes.

An OAuth 2.0 / OpenID Connect-based authentication feature was also implemented as an enhancement to the application.
